## 📁 Структура репозитория

- `БСБД_Корецкий_ПС_ЛР2.docx` — Итоговый отчёт в формате Microsoft Word (шрифт Times New Roman 14 пт, полуторный интервал, ГОСТ-оформление, перенос таблиц с надписью «Продолжение таблицы», монохромное оформление без цветных стилей).
- `БСБД_Корецкий_ПС_ЛР2.pdf` — Скомпилированный PDF отчёта.
- `report.typ` — Исходный код отчёта в системе Typst (ровно 24 страницы).
- `images/` — 28 скриншотов терминалов выполнения всех шагов (pgadmin_fig01.png — pgadmin_fig28.png).
- `migrations/` — SQL-миграции базы данных PostgreSQL:
  - `001_create_roles_and_base_schema.sql` — Создание ролей и схемы базы данных.
  - `002_security_definer_functions.sql` — SECURITY DEFINER функции с контролем вызовов и аудитом.
  - `003_check_vs_trigger_benchmark.sql` — Сравнение CHECK-ограничения и триггера бизнес-логики.
- `scripts/` — Скрипты для бенчмарков, тестов и автоматической генерации отчёта:
  - `run_all_tests.py` — Запуск 12 тест-кейсов матрицы разграничения доступа.
  - `run_benchmark.py` — Замер производительности CHECK vs BEFORE-триггер (10 000 вставок).
  - `build_chubreich_style_docx.py` — Генератор DOCX-отчёта по ГОСТ.
- `docker-compose.yml`, `.env`, `Makefile` — Среда развёртывания PostgreSQL.
